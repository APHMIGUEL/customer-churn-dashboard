# 📊 Customer Churn Analytics Dashboard

## 📌 Descripción del Proyecto

Este proyecto consiste en una aplicación interactiva desarrollada con Streamlit para realizar un Análisis Exploratorio de Datos (EDA) sobre el dataset Telco Customer Churn.

El objetivo principal es analizar el comportamiento de los clientes de una empresa de telecomunicaciones e identificar patrones asociados a la fuga de clientes (Churn), utilizando técnicas de análisis descriptivo y visualización de datos.

La aplicación permite explorar información del dataset mediante gráficos interactivos, estadísticas descriptivas y filtros dinámicos.

# 📌 Conclusiones

- Los contratos mensuales presentan mayor tasa de abandono.
- Los clientes nuevos son más propensos al churn.
- Los clientes con mayores cargos mensuales muestran mayor fuga.
- Los clientes con mayor permanencia presentan mayor fidelización.
- La retención de clientes resulta más rentable que adquirir nuevos clientes.
